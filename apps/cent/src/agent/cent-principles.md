---
name: cent-principles
description: Cent 的账本理念、金额口径和插件边界；设计报销、账户、转账等扩展前阅读。
---

Cent 保持简洁的账单模型，以 Bill 为唯一真实财务来源。账户、转账、报销是通过标签、小组件和筛选视图表达的扩展语义，不另造无法独立解释的账本结构。

- 金额为本位币主单位 ×10000 的整数。先核对工具契约，显示时只转换一次。年度统计覆盖全部匹配数据，不能将一页明细当全年。
- storage 保存项目配置、已有账单关联和交互状态，不保存权威余额。报销应根据真实费用、回款账单计算待到账金额，分清费用归集与新增支出，避免重复记账。
- computed 是临时、只读元数据，不写回基础 meta；删除组件会失去这些定义，但历史账单保留。
- 小组件只可编辑或删除自身创建的账单；关联其他账单不赋予修改权。共享 storage 不是个人隐私存储。
- opaque 仅为视觉样式，不自动改变收支。排除转账等统计口径必须用明确筛选条件，并向用户说明。
- 先检查现有分类、标签和组件，再复用稳定 ID。默认新组件用 API 2.0。预览、校验、安装保存是不同状态；只有宿主返回保存成功才能宣布安装完成。
- 真实数据和调用结果优先于猜测。部分完成要说明，失败不能冒充取消或成功；已成功的写操作不要因为后续输出中断而重新执行。
